# Сборка Leostryx

[Главная](../README.md) · [Настройка](USAGE.md) · [История версий](../CHANGELOG.md)

## Что хранится в репозитории

Это рабочее дерево для **перепаковки APK**, включая DEX, Android-ресурсы, веб-интерфейс и скрипты окружения. Оно не является полным исходным проектом всех компонентов: наличие `classes*.dex` или готового JS-бандла не заменяет исходники Java/Kotlin и React.

| Путь | Назначение |
|---|---|
| `app/` | Распакованное содержимое базового APK |
| `app/assets/web/` | Веб-интерфейс, локализация и доработки |
| `app/assets/runtime/` | Окружение ядра, библиотеки и манифесты |
| `app/assets/env/` | Bootstrap, пакетный менеджер и overlay |
| `variants/bypass/` | Файлы, заменяемые при сборке Bypass |
| `rebuild.py` | Упаковка, выравнивание и подпись APK |
| `compress-map.json` | Режимы сжатия файлов APK |
| `tools/` | Утилиты подписи и обслуживания окружения |
| `assets/` | Баннер и скриншоты документации |
| `docs/` | Руководства и подробная история разработки |

## Ограничения текущего дерева

При проверке ветки `main` 10 ноября 2026 года обнаружены отсутствующие входные файлы, на которые ссылается `rebuild.py`:

| Файл | Для чего требуется |
|---|---|
| `tools/brand.py` | Импортируется сборщиком для наложения брендинга; без модуля скрипт не запускается |
| `app/assets/web/brand/config.json` и наборы брендинга | Настройки и ресурсы, упоминаемые в описании версии 3.0.3 |
| `dist/antigravity-signing.p12` | Ожидаемый скриптом ключ подписи |
| `app/assets/runtime/bin/liblanguage_server.so` | Бинарник ядра Standard, исключённый из Git |
| `variants/bypass/assets/runtime/bin/liblanguage_server.so` | Бинарник ядра Bypass, исключённый из Git |

Поэтому **одного клонирования репозитория недостаточно для сборки**. Необходимо восстановить соответствующие версии недостающих компонентов. В опубликованных релизах 3.0.3 и 3.0.4 отдельного полного архива `Leostryx-repo.zip` нет; автоматически создаваемый GitHub Source code содержит только файлы Git.

Бинарники ядра можно извлечь из APK соответствующего варианта в `assets/runtime/bin/liblanguage_server.so`. Остальные отсутствующие компоненты необходимо получить из рабочего дерева сборки. Не смешивайте ядро одной версии с манифестом другой: проверка целостности зависит от SHA-256.

## Подготовка

- Python 3 и OpenJDK 17.
- `apksigner` в `PATH` либо имеющийся `tools/uber-apk-signer.jar` и Java.
- Восстановленные компоненты брендинга и их Python-зависимости.
- Полное дерево APK и подходящие бинарники обоих вариантов.
- Собственный ключ подписи либо ключ, которым подписана обновляемая установка.

Текущий скрипт ожидает ключ в `dist/antigravity-signing.p12`; параметры подписи заданы внутри `sign()`. Для своего ключа адаптируйте путь, alias и способ передачи паролей. Совместимость обновления определяется сертификатом подписи и идентификатором пакета, а не именем APK.

## Команды

После восстановления входных файлов:

```bash
python3 rebuild.py both
python3 rebuild.py standard
python3 rebuild.py bypass
```

Первая команда собирает оба варианта. Вызов без аргументов эквивалентен `both`.

Готовые файлы: `dist/signed/standard.apk` и `dist/signed/bypass.apk`. Версионные названия в Releases назначаются отдельно; скрипт сам не создаёт имена вида `Leostryx-3.0.4-standard.apk`.

## Как формируется вариант

Сборщик упаковывает `app/`, применяет замену файлов для Bypass, затем накладывает брендинг, выравнивает несжатые записи и подписывает APK. Изменения интерфейса находятся в `app/assets/web/`.

Для изменений JVM/Flutter и overlay смотрите [Flutter/Dart](flutter-toolchain.md) и [JVM/jadx](jadx-fixes.md). Приведённые здесь команды проверены по коду сборщика; пересборка APK в рамках обновления документации не выполнялась.
